# dynamic-AI-Medical-Guardian-NEMOS.
Dynamic AI Medical Guardian 🩺🤖

AI-Powered Personal Medical Assistant & Emergency Guardian

📌 About the Project

Dynamic AI Medical Guardian is an AI-powered medical assistant designed to help users manage medical records, prescribed medicines, reminders, and emergency information. It uses DeepSeek AI to support natural Tamil, Tanglish, and English conversations.

✨ Features

- 🤖 AI chat powered by DeepSeek API
- 🗣️ Tamil, Tanglish, and English conversations
- 💊 Medicine schedule and reminders
- 📋 Personal medical profile
- 🚨 Emergency medical dossier with PIN access
- 📊 Weekly medicine reports
- 🎙️ Voice interaction
- ⚡ Futuristic Jarvis-style interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js and Express.js
- DeepSeek API

🚀 Getting Started

1. Install Node.js.
2. Download or clone this repository.
3. Install dependencies using "npm install".
4. Add your DeepSeek API key to a local ".env" file.
5. Start the backend server.
6. Open the project in your browser.

🔐 Privacy & Security

The project aims to protect personal medical information. Keep API keys private and never upload them to GitHub. Medical information should only be shared with an AI service with the user's informed consent.

⚠️ Important Note

This project is a prototype, not a replacement for professional medical advice. The current AI features require an internet connection. Medicine details should follow a qualified healthcare professional's instructions.
