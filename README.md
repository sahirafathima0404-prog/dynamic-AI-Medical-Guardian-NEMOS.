Dynamic AI Medical Guardian

About

Dynamic AI Medical Guardian is an HTML-based medical assistant prototype designed to help users access medical information through a simple interface.

Working Features

- Assistant setup and naming interface.
- Permission settings screen.
- PIN-based access interface.
- Emergency medical dossier access using a dedicated PIN.
- Main medical assistant chat interface.
- Medical information and medicine details entry.
- Jarvis-inspired user interface.

Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser-based storage, where implemented

Project Status

This project is a prototype under development. The features listed above describe the implemented interface and functionality; external AI integration, reminders, and other features should only be listed as working after they have been tested.

Disclaimer
